# 🏎️ Formula 1 Live Dashboard (Streamlit + Ergast API)

This project is a real-time Formula 1 dashboard using Streamlit and the Ergast Developer API.

## Features
- Live driver and constructor standings
- Points progression across races
- Qualifying vs Race position delta
- Fastest lap times per race
- Pit stop duration analysis

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
